INDEX.JS

“index.js is basically the main file that runs the project...

At the top, I’m importing fs so I can write the report file, puppeteer so I can control the browser, and then I’m bringing in the calculation and formatting functions from arbitrageCalc.js.

One thing I added here is runtime options...

The scraper itself uses Puppeteer to open the MLB odds page on VegasInsider...

The getTeamData function is where I actually pull useful data from the page...

After that, checkForArbitrage pairs each top team with the matching bottom team...

At the end, I sort the opportunities from highest guaranteed payout to lowest, print them in the terminal, and generate an HTML report.”
